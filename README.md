# ondotori-repo

これは、温度データロガーで計測・蓄積されたデータがオンプレミスのFTPサーバーに転送された後、<br>
ファイルの拡張子を「.trz」⇒「.csv」に変換した上で、保存用フォルダに自動転送する為のアプリケーションです。<br>
(現時点では未完成・動作は未確認ですので、インストールは出来ません)<br>
[プログラムの作成に至った経緯については、こちらをご覧下さい] (data/温度管理用サンプルコード_nakam07.pptx) <br>

今回は実機は購入せず、それを用いた動作確認を見送る事に決定。<br>

それに合わせて、dummyの"ondotori.c"を一部変更。<br>
